## 📌 Overview

**Startup-Intel-AI** is a premium AI-powered chatbot that delivers brutally honest, data-driven feedback on startup ideas. Built with a strong focus on **Frontend Thinking**, it combines modern glassmorphic UI, smooth animations, and structured AI insights to help founders validate ideas before investing time and resources.

> 💡 *Stop guessing. Get real, unfiltered feedback on your startup idea in seconds.*

---

## ✨ Features

### 💡 Instant Validation
Get immediate AI-powered feedback on any startup idea without waiting.

### 📊 Structured Analysis
Every response includes a comprehensive breakdown:

| Category | Details |
|----------|---------|
| 📈 **Market Potential** | Market size, growth trends, timing |
| 🎯 **Target Audience** | Pain points, user personas, reachability |
| 🏆 **Competition** | Competitive moats, market gaps, differentiation |
| 💰 **Monetization** | Revenue models, pricing strategies |
| ⚠️ **Risks & Challenges** | Potential obstacles, mitigation strategies |
| ✅ **Verdict** | "Promising" 🚀 or "Needs Refinement" ⚠️ |

### 🎨 Premium UI/UX
- **Glassmorphism** with modern gradients
- **Smooth micro-interactions** and transitions
- **Clean chat interface** with Material UI (MUI v6)
- **Fully responsive** across all devices
- **Markdown support** for formatted AI responses

## 🚀 Getting Started

### 1️⃣ Prerequisites

- **Node.js** (v18 or higher)
- **npm** or **yarn** package manager

### 2️⃣ Installation

```bash
# Clone the repository
git clone https://github.com/your-username/startup-intel-ai.git

# Navigate to project directory
cd startup-intel-ai

# Install dependencies
npm install


3️⃣ API Configuration
Create a .env file in the root directory:

env
VITE_OPENROUTER_API_KEY=your_openrouter_api_key_here
⚠️ Note: If no API key is provided, the app will automatically run in Mock Mode for demonstration purposes.

4️⃣ Run the Application
bash
npm run dev
The app will be available at http://localhost:5173
